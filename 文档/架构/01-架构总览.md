# Focusory 架构总览

## 目标与基线

架构服务于「番茄钟原型初版」的生产实现，采用本地优先、云端同步的 macOS 客户端架构。

## 系统组成

- SwiftUI macOS 客户端：实现登录、任务、专注、休息、统计和同步状态界面。
- 领域层：实现待办/持续任务规则、计时状态机、会话与统计口径。
- SwiftData 本地存储：保存账户副本、任务、每日进度、会话和待同步变更。
- Python 业务后端：使用 Python 3.12.10、FastAPI/Uvicorn 和 Pydantic 2 验证登录结果，提供任务、会话、统计和同步 API。
- MySQL：使用 SQLAlchemy 2 同步 Session、PyMySQL 和 Alembic 保存与迁移云端账户及业务数据。
- Apple/微信身份服务：提供第三方身份证明；同一 Focusory 账户可同时绑定两种身份并通过任一方式访问同一份业务数据。

## 主要依赖方向

```text
SwiftUI 视图
    ↓
功能状态模型
    ↓
领域规则与用例
    ↓
存储、时钟、通知、认证与 API 协议
    ↓
SwiftData / macOS 系统能力 / Python API
```

领域层不依赖 SwiftUI、SwiftData 或具体网络库。

## 关键数据流

1. 用户操作先通过领域规则验证。
2. 任务、会话和每日进度先原子写入本地。
3. 界面立即从本地数据更新。
4. 同步模块在后台将幂等变更提交到后端。
5. 后端返回新的同步游标，客户端拉取增量变更并合并。

## 边界

- 当前不包含 macOS 菜单栏入口。
- `focusory_container_mcp` 仅是开发辅助服务，不是产品业务后端。
- 趋势统计和 AI 功能不进入当前数据流。
