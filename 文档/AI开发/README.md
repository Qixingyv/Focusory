# AI 开发文档

本目录记录 Focusory 使用 ChatGPT/Codex 进行设计和验收、使用 OpenCode 与本地模型进行开发时的人类可读流程、配置边界、辅助工具和决策历史，不存放智能体自动加载的配置文件。

## 阅读顺序

1. [`01-AI开发流程.md`](./01-AI开发流程.md)：从产品基线到实现、验证和复盘的步骤，以及可复用提示词。
2. [`02-Codex配置说明.md`](./02-Codex配置说明.md)：仓库根目录下 Codex 文件的职责和维护边界。
3. [`03-容器MCP服务器.md`](./03-容器MCP服务器.md)：开发辅助容器工具的边界、架构和安全规则，不属于产品运行时。
4. [`04-决策记录.md`](./04-决策记录.md)：影响产品、架构和 AI 协作方式的重要决策及其历史。
5. [`任务卡/README.md`](./任务卡/README.md)：分支与任务卡索引、中文分支说明要求和任务卡模板；同目录保存由 ChatGPT/Codex 确认、可交给开发 AI 独立实现和验证的单任务说明。

## 维护边界

- 产品行为与业务规则写入 `文档/产品/`，架构契约写入 `文档/架构/`，这里仅说明 AI 协作方式与工具。
- 长期且跨任务成立的约束写入根目录 `AGENTS.md`；特定工作流写入 `.agents/skills/`。
- 已形成影响范围较大的选择时写入决策记录；尚未确定的事项不以猜测补齐。
- 提示词只是任务入口，不能替代产品需求、验收标准或项目规则。

Swift 与操作系统资料位于 `文档/学习/`，它们不作为产品行为或架构契约。
