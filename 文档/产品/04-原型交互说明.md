# Focusory 原型交互说明

## 1. 文档定位

- 目的：记录「番茄钟原型初版」的当前信息架构、页面状态、交互和视觉约束，用于 SwiftUI 实现与 UI 验收。
- 受众：产品、设计、macOS 客户端和 UI 测试人员。
- 交付物：页面清单、状态矩阵、核心路径和视觉 Token。
- 交付标准：原生客户端可对照原型完成布局、文案、按钮可用性和状态切换验收。

## 2. 原型基线

- 类型：React + TypeScript 可交互高保真窗口原型。
- 产品实现：SwiftUI 原生 macOS 客户端。
- 用法：参考交互和视觉，不直接移植 React 组件或内存状态实现。
- 任务模式：只有「待办」和「持续」。
- 视觉实现基线：以 [`05-原型UI规范.md`](./05-原型UI规范.md) 中的颜色、尺寸、间距、组件和交互状态为准；其中 CSS、Tailwind、JSX 和内联 SVG 是原型表达方式，SwiftUI 实现需映射为 Asset Catalog、原生布局和 SF Symbols。

## 3. 信息架构

```text
未登录
 ├─ Apple 登录
 └─ 微信扫码弹窗

已登录主窗口
 ├─ 系统标签侧边栏
 │   ├─ 任务
 │   ├─ 专注
 │   └─ 统计
 ├─ 页面头部
 │   ├─ 当前页标题
 │   ├─ 当前页说明
 │   └─ 同步状态
 └─ 账户区
     └─ 退出登录
```

## 4. 登录页

### 默认状态

- 居中白色卡片，使用 macOS 窗口装饰圆点。
- 应用图标、标题「开始一段安静的专注」和说明「围绕任务计时，并自动记录今天的投入。」
- 主按钮「使用 Apple 登录」。
- 次按钮「微信扫码登录」。

### 交互状态

- Apple 登录处理中显示轻量进度并禁用按钮。
- 微信弹窗包含待扫码和已扫码待确认两种状态。
- 取消关闭弹窗；成功后进入主窗口。

## 5. 主窗口

### 布局

- 顶层导航使用 macOS 系统 `TabView` 的可适应侧边栏样式，由系统管理侧边栏宽度、背景、选择、键盘焦点和显示行为。
- 侧边栏从上到下为应用品牌、任务、专注、统计和本地账户区；品牌使用系统侧边栏 header 承载，账户区使用 bottom bar 固定在底部，与顶层导航保持明确分区。
- 主内容区使用浅灰背景，页面内容居中收敛到最大 840 pt，窗口变宽时保持两侧留白，避免元素过度拉伸或偏在一侧。
- 页面头部与正文使用同一内容边界，左侧展示页标题和简短说明，右侧使用低对比胶囊展示同步状态；不再使用横跨窗口的独立白色顶栏。

### 导航

- 默认选中任务标签；点击系统标签切换顶层页面，不改变正在运行的计时状态。
- 从任务行开始专注时，应用以同一标签选择状态切换到专注页。
- 当前页使用系统选中状态、图标和文字共同表达，不自行模拟侧边栏选择语义。

## 6. 任务页

### 页头

- 左侧为「进行中」、「已完成」、「已放弃」分段控件及数量。
- 右侧为番茄色「新建任务」按钮。
- 分段控件与主按钮位于同一内容容器和同一水平基线，两端对齐。

### 空状态

- 空任务状态使用 300 pt 高的白色描边卡片，不随窗口高度无限拉伸。
- 卡片内按图标、标题、说明和主操作形成垂直层级；进行中为空时提供「创建第一个任务」，其他状态只解释内容将出现在哪里。

### 进行中任务行

- 展示任务名、模式标签和进度。
- 持续任务根据配置附加日期范围、今日进度或「今日已达标」；今日达标时提供追加入口。
- 任务操作（开始专注、完成任务、追加目标、编辑和删除/放弃）常驻显示，不依赖鼠标悬停，保证键盘和 VoiceOver 可以直接到达；悬停和选中只改变边框与背景等视觉强调。
- 完成任务使用行内确认区。

### 待办系统达标

- 使用低饱和绿色强调。
- 显示「任务已按计划完成」和当前进度。
- 提供「追加 1 个番茄钟」和「修改追加数量」。

### 新建与编辑弹窗

- 使用「待办/持续」两段式模式选择。
- 待办展示名称、目标番茄数、专注时长和休息时长。
- 持续展示名称、计划周期开关、每日目标开关、专注时长和休息时长。
- 开启开关后自然插入对应字段；关闭时不保留无效空占位。
- 编辑时模式不可切换；已有记录的持续任务配置开关锁定。

## 7. 专注页状态

| 状态 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 无任务 | 空状态、弱化的 25:00 | 创建任务 |
| 空闲 | 任务选择、模式标签、满环倒计时 | 开始专注 |
| 专注中 | 番茄色进度环、任务名和剩余时间 | 暂停 |
| 已暂停 | 橙色状态文字和冻结的进度环 | 继续专注、结束本次 |
| 专注完成 | 绿色完成反馈、任务进度 | 开始休息、返回专注 |
| 休息中 | 绿色进度环和休息剩余时间 | 跳过休息并立即专注、结束休息 |

结束本次弹窗的顺序为：「记录为完成」、「放弃本次」、「继续专注」。

## 8. 统计页

- 顶部并排显示「完成番茄钟」和「专注总时长」。
- 下方为「今日记录」列表，按时间倒序。
- 无数据时使用低对比空状态，不显示伪造的示例统计。

## 9. 全局反馈

- 同步状态：已同步、离线使用中、等待同步、正在同步和暂时无法同步。
- 休息自然结束时显示 4 秒轻量 Toast。
- 删除任务、放弃任务和退出登录使用明确确认弹窗。
- 危险操作不得是默认回车操作。

## 10. 视觉规范

### 颜色

- 专注主色：`#C25338`。
- 休息与达标：`#547A66`。
- 警告：`#B7791F`。
- 危险：`#C93C37`。
- 主文本：`#1D1D1F`。
- 次文本：`#6E6E73`。
- 弱文本：`#9E9EA8`。
- 页面背景：`#F5F5F7`。
- 边框：`#E5E5EA` 或 `#D2D2D7`。

### 形状与动效

- 卡片和弹窗使用 12–16 pt 圆角，按钮使用 8–12 pt 圆角。
- 状态切换使用短时透明度或颜色过渡。
- 不使用渐变、玻璃拟态、粒子、彩带、持续闪烁或弹跳奖励。
- 状态不只依赖颜色，同时使用文字或图标。

## 11. 核心原型路径

1. Apple 登录或微信扫码 → 主窗口。
2. 无任务 → 新建待办 → 自动选中 → 开始专注。
3. 新建持续 → 独立切换计划周期和每日目标。
4. 专注中 → 暂停 → 继续。
5. 已暂停 → 结束本次 → 记录为完成/放弃本次/继续专注。
6. 自然完成 → 开始休息 → 跳过或结束休息。
7. 待办达标 → 追加 1 个或自定义数量 → 恢复进行中。
8. 无记录任务 → 删除确认；有记录任务 → 放弃确认。
9. 完成会话 → 今日统计和明细更新。
10. 退出登录 → 确认 → 登录页。

## 12. 不属于当前原型的界面

- macOS 菜单栏状态项和弹出菜单。
- 持续任务过期和延期恢复界面。
- 趋势统计、AI 复盘、项目或标签管理。
