# Focusory 产品需求

## 文档定位

- 目的：将「番茄钟原型初版」中已展示、可操作的行为固化为 Focusory 当前产品基线。
- 受众：产品、macOS 客户端、Python 后端、测试和 AI 开发协作者。
- 基线：以 2026-08-29 的「番茄钟原型初版」演示代码为准；2026-08-31 确认的「同一账户可同时绑定 Apple 和微信」覆盖原型中的单一登录方式假设。旧的三模式方案不再是当前需求。

## 产品目标

Focusory 是一款安静、轻量的 macOS 番茄钟应用。用户围绕任务开始一轮专注，在完成后自动保存专注记录，并通过今日统计了解真实投入。

产品原则：

- 番茄钟服务于实际目标，不使用超额、奖励或游戏化刺激用户追求数量。
- 专注过程优先保持低干扰，危险或不可恢复操作必须确认。
- 统计来自已保存的专注会话，不重复维护一份可能失真的统计结果。

## 信息架构

### 未登录

- Apple 登录入口。
- 微信扫码登录入口及扫码状态弹窗。

### 已登录

主窗口包含三个一级页面：

1. `任务`：管理进行中、已完成和已放弃任务。
2. `专注`：选择任务并完成专注与休息计时。
3. `统计`：展示今日完成番茄数、专注总时长和会话明细。

全局状态包含用户信息、Apple/微信绑定状态、退出登录入口和弱化的同步状态。

## 当前 MVP 功能

### 账户

- 提供 Apple 登录和微信扫码登录。
- 同一 Focusory 账户可同时绑定一个 Apple 账号和一个微信账号，通过任一已绑定账号登录均进入同一工作空间。
- 用户只能在已登录的账户设置中绑定另一种登录方式；系统不根据邮箱或昵称自动合并账户。
- 可解绑其中一种登录方式，但不允许解绑当前账户的最后一个登录身份。
- 登录处理中禁止重复提交。
- 退出登录需要二次确认；退出后回到登录页。

### 任务

- 任务只有两种模式：`待办` 和 `持续`。
- 创建后不允许在两种模式之间转换。
- 两种模式都可设置任务名称、专注时长和休息时长。
- 待办任务必须设置目标番茄数；达标后系统标记「任务已按计划完成」，用户可直接继续，也可追加数量并按新目标推进。
- 持续任务不设整体番茄目标，可独立开启「设置计划周期」和「设置每日目标」。
- 计划周期用于限制开始日期并在任务行展示日期范围；当前原型不包含过期与延期恢复流程。
- 每日目标用于展示今日进度和「今日已达标」状态；达标不会自动完成整个任务。
- 今日达标后仍可直接继续专注；用户可选追加今日目标，追加只影响今日，不修改未来日期的每日目标。
- 用户可手动完成整个任务，需要二次确认，完成后不可恢复。
- 无历史记录的任务可删除；已有记录的任务只能放弃，并保留历史记录和统计。

任务模式的定位对比如下。详细约束及其编号以 [`02-用户故事.md`](./02-用户故事.md) 中的 `BR-TASK-*`、`BR-TODO-*` 和 `BR-ONGOING-*` 为准，不在本文件重复定义。

| 对比项 | 待办 | 持续 |
| --- | --- | --- |
| 使用场景 | 可以估算总番茄数 | 长期投入或按日期记录 |
| 总目标 | 必填，只能增加 | 无 |
| 计划周期 | 无 | 可选 |
| 每日目标 | 无 | 可选 |
| 达标反馈 | 按计划完成，整体仍进行中 | 今日已达标，整体仍进行中 |
| 达标后继续 | 可直接继续，也可增加总目标 | 可直接继续，也可增加今日目标 |
| 最终完成 | 用户确认后手动完成 | 用户确认后手动完成 |

### 专注与休息

- 开始专注前必须选择一个可用任务。
- 计时状态包含空闲、专注中、已暂停、专注完成和休息中。
- 专注中可暂停；暂停后可继续或结束本次。
- 结束本次时可选择「记录为完成」、「放弃本次」或「继续专注」。
- 自然完成或「记录为完成」都保存专注会话；放弃本次不保存。
- 专注完成后用户手动开始休息或返回专注。
- 休息中可跳过休息并立即开始下一轮，也可直接结束休息。
- 休息不生成会话，不进入统计。
- 专注完成和休息自然结束触发低干扰的系统通知与提示音；休息自然结束后显示短时轻量提示。

### 统计

- 今日完成番茄数等于今日专注会话数。
- 今日专注总时长等于今日会话实际专注秒数之和。
- 会话明细按结束时间倒序展示任务名、起止时间和实际时长。
- 跨越零点的会话归入结束时的本机日期。

### 本地数据与同步

- 生产实现必须使任务和专注会话在应用重启后仍然存在。
- 同步状态使用 `synced`、`offline`、`pending`、`syncing` 和 `failed`。
- 离线时允许使用本机数据继续创建任务、计时和查看统计。
- 退出登录后清理当前账户的本机数据和待同步变更，云端数据保留。

## 验收标准

- 客户端的页面、文案、主要交互和任务模式与当前原型一致。
- 应用中只出现「待办」和「持续」两种任务模式。
- 用户能完成创建任务、开始、暂停、继续、自然完成、中途记录完成、放弃本次和手动休息流程。
- 待办达标后可直接继续或追加新目标；手动完成后不可恢复。
- 绑定 Apple 和微信后，使用任一方式重新登录都显示同一账户的任务、会话和统计。
- 已属于另一 Focusory 账户的第三方身份不得被重复绑定；最后一个登录身份不得解绑。
- 持续任务的计划周期和每日目标可独立配置，今日达标不会自动完成整个任务，也不阻止继续当日专注。
- 计时运行中或暂停中不能切换、最终完成、删除或放弃当前任务；任务编辑不得重算本轮倒计时。
- 任务和会话可本地持久化，今日统计可从真实会话正确计算。
- 后端不可用时，本地计时与记录不中断。
- 关键计时状态、任务规则、日期边界和统计口径具备自动化测试。

## 当前不包含

- 第三种任务模式。
- 项目、标签、优先级、子任务或多人协作。
- 趋势图、周报和复杂数据仪表盘。
- AI 复盘、AI 任务推荐、社交分享和游戏化。
- macOS 菜单栏常驻入口。
- 持续任务过期、延期恢复和历史每日状态编辑。
