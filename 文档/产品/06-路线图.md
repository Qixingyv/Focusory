# Focusory 路线图

## 路线图基线

路线图以 [`01-产品需求.md`](./01-产品需求.md) 和 [`02-用户故事.md`](./02-用户故事.md) 为产品边界。开发顺序先建立本地闭环，再接入账户和同步；阶段划分不改变最终原型行为。

## 阶段 1：原型界面与领域模型

- 建立任务、专注、统计三页导航和主窗口布局。
- 建立待办、持续两种模式的任务模型。
- 建立计时器状态机和专注会话模型。
- 完成新建、编辑、手动完成、删除与放弃的原型界面。

## 阶段 2：本地专注闭环

- 实现开始、暂停、继续、自然完成和中途结束。
- 实现会话保存、今日统计和休息流程。
- 实现待办自动达标与追加。
- 实现持续任务的计划周期展示、开始日期限制、每日进度和今日追加。

## 阶段 3：本地可用性与可靠性

- 使用 SwiftData 保存任务、每日进度和专注会话。
- 实现应用重启后数据恢复和计时恢复。
- 接入专注与休息结束的系统通知和提示音。
- 为计时、任务规则、日期归属和统计口径增加自动化测试。

## 阶段 4：账户、后端与同步

- 实现 Apple 登录、微信扫码登录，以及同一 Focusory 账户的 Apple/微信身份绑定与安全解绑。
- 实现 Python 业务 API 和 MySQL 数据表。
- 实现本地优先的变更队列、同步状态、自动重试和退出清理。
- 验证后端不可用时不影响本地专注闭环。

## 阶段 5：原型一致性收尾

- 统一颜色、字体层级、间距、圆角、空状态和危险操作。
- 补齐键盘操作、旁白标签、错误状态和弱网状态。
- 按原型核心流程执行 UI 验收。

## 后续候选

以下内容不属于当前原型基线，需要新的用户故事和原型后才能进入开发：

- macOS 菜单栏常驻入口。
- 周、月趋势统计。
- AI 复盘与任务推荐。
- 持续任务的过期、延期恢复和可编辑历史日状态。
