# Focusory 原型 UI 规范

> 本文档记录高保真原型的视觉语言、布局规则和组件表现。CSS、Tailwind、JSX 与内联 SVG 片段只用于说明原型参数，不是 macOS 生产代码；SwiftUI 实现应使用等价的原生布局、Asset Catalog 和 SF Symbols，并保持视觉语义一致。具体代码写法以 [`09-SwiftUI样式规则.md`](../架构/09-SwiftUI样式规则.md) 为准。

---

## 一、设计哲学

Focusory 是一款 macOS 风格的专注工具。界面遵循以下原则：

- **克制**：信息密度低，呼吸感强，不堆砌元素
- **层次清晰**：通过字号、颜色、透明度区分主次，不用加粗代替层次
- **交互收敛**：操作在需要时出现（hover、confirm），不常驻干扰阅读
- **一致性优先**：所有页面共用同一套 token，不得引入新颜色

## 三、字体与字号

字体：**Inter**（通过 Google Fonts 引入，`src/index.css` 已配置）。

SwiftUI 生产代码保留以下字号和字重，但通过 `FocusoryTypography` 的语义角色引用，不在具体 View 中重复 `.system(size:weight:)`。

### 字号规范

| 场景 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 弹窗标题 | `text-[14px]` | `font-semibold` | `#1D1D1F` |
| 页面标签、区块标题 | `text-[11px]` | `font-semibold` 且 `uppercase tracking-wider` | `#9E9EA8` |
| 任务名称 | `text-[13px]` | `font-medium` | `#1D1D1F` |
| 按钮文字 | `text-[13px]` | `font-medium` | 取决于按钮类型 |
| 表单 label | `text-[11px]` | `font-medium` | `#6E6E73` |
| 辅助说明 | `text-[11px]` | `font-normal` | `#9E9EA8` |
| 元信息/徽标 | `text-[10px]` | `font-medium` | 取决于语义 |
| 计时器大字 | `text-[52px]` | `font-light` 且 `tabular-nums tracking-tight` | `#1D1D1F` |

**禁止**：`text-base`、`text-sm`、`text-xs` 等 Tailwind 语义字号——所有字号用 `text-[Npx]` 精确指定。

## 五、组件规范

### 5.1 页面布局

```
┌─────────────────────────────────────────────────┐
│  系统标签侧边栏 │  主内容区 flex-1 overflow-auto  │
│  自适应宽度/背景│  bg-[#F5F5F7]                   │
│                │  ┌─ 居中内容 max-w-[840px] ─┐  │
│                │  │ 页面头部 + 页面正文       │  │
│                │  └───────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

- 侧边栏使用 `TabView` 的 `.sidebarAdaptable` 样式，由 macOS 管理宽度、背景、选择和键盘交互
- 品牌标识置于 `tabViewSidebarHeader`，本地账户和退出入口置于 `tabViewSidebarBottomBar`，固定在侧边栏底部且不随标签列表滚动
- 主内容区 `flex-1 overflow-auto`，背景 `#F5F5F7`
- 列表页的页面头部和正文共用 840 pt 最大宽度并水平居中，左右安全间距为 32 pt
- 页面头部不使用横跨窗口的白色栏；标题与说明左对齐，同步状态以白色描边胶囊靠右显示
- 专注页主体保持 `max-w-md` 居中

### 5.2 任务卡片（ActiveTaskRow）

```
┌─────────────────────────────────────┐
│ 任务名 [模式标签]                    │  ← text-[13px] font-medium
│ ████░░ 1/3 个番茄钟                 │  ← 进度条 + 元信息
│ 2024-01-01 至 2024-03-31            │  ← text-[11px] #C7C7CC
└─────────────────────────────────────┘
                        [开始专注] [完成任务] [✎] [🗑]  ← hover 时出现
```

- 默认态：`bg-white border border-[#E5E5EA] rounded-xl`
- hover 态：`border-[#D2D2D7]`（通过 `hover:border-[#D2D2D7]`）
- 选中态（当前专注任务）：`bg-[#FBEFED] border-[#EFD3CB]`，任务名变 `#C25338`
- `transition-all` 保证状态切换平滑

**进度条**：高度 `h-1`，宽度 `w-16`，背景 `bg-[#E5E5EA]`，进度色取决于模式（红/绿）

### 5.3 模式标签（ModeTag）

```tsx
// 待办
<span className="text-[10px] font-medium px-1.5 py-0.5 rounded border bg-[#FBEFED] text-[#C25338] border-[#EFD3CB]">
  待办
</span>

// 持续
<span className="text-[10px] font-medium px-1.5 py-0.5 rounded border bg-[#EDF3F0] text-[#547A66] border-[#C6D8CF]">
  持续
</span>
```

模式标签紧跟任务名后，`gap-2`。**不可单独用颜色区分模式，必须有标签文字**。

### 5.4 按钮系统

#### 主要按钮（CTA）
```
bg-[#C25338] text-white rounded-xl px-8 py-2.5 text-[13px] font-medium
hover:bg-[#B04A32] transition-colors shadow-sm
disabled:opacity-40 disabled:cursor-not-allowed
```

#### 绿色确认按钮（完成类操作）
```
bg-[#547A66] text-white rounded-xl px-8 py-2.5 text-[13px] font-medium
hover:bg-[#476957] transition-colors shadow-sm
```

#### 次要按钮（文字操作）
```
text-[#6E6E73] text-[13px] font-medium
hover:text-[#1D1D1F] transition-colors
（无背景、无边框）
```

#### 描边按钮（列表行内操作）
```
// 开始专注（小）
bg-[#C25338] text-white rounded-lg px-2 py-1.5 text-[11px] font-medium
hover:bg-[#B04A32] transition-colors

// 完成任务（小描边）
border border-[#547A66] text-[#547A66] rounded-lg px-2 py-1.5 text-[11px] font-medium
hover:bg-[#EDF3F0] transition-colors
```

#### 图标按钮（编辑/删除）
```
p-1.5 rounded-md text-[#9E9EA8]
hover:text-[#1D1D1F] hover:bg-[#F5F5F7] transition-colors  // 编辑
hover:text-[#C93C37] hover:bg-red-50 transition-colors      // 删除
```

**规则**：
- 所有按钮必须有 `transition-colors`
- 危险操作（删除、放弃）必须有二次确认，不得直接执行
- disabled 态统一 `opacity-40 cursor-not-allowed`

### 5.5 分段控制器（Segmented Control）

用于 Tab 切换，例如"进行中 / 已完成 / 已放弃"：

```tsx
<div className="flex gap-0.5 bg-[#E5E5EA] rounded-lg p-0.5">
  <button className="px-3.5 py-1.5 rounded-md text-[13px] font-medium
    bg-white text-[#1D1D1F] shadow-sm">  {/* 选中 */}
    进行中
  </button>
  <button className="px-3.5 py-1.5 rounded-md text-[13px] font-medium
    text-[#6E6E73] hover:text-[#1D1D1F]">  {/* 未选中 */}
    已完成
  </button>
</div>
```

### 5.7 表单控件

**输入框**
```

outline-none focus:border-[#C25338] transition-colors
错误态：border-[#C93C37] bg-red-50
```

**Label**
```
block text-[11px] font-medium text-[#6E6E73] mb-1.5
```

**错误提示**
```
mt-1 text-[11px] text-[#C93C37]
```

**Stepper（数字步进器）**
```
border border-[#D2D2D7] rounded-lg overflow-hidden bg-white
  − 按钮：px-3 py-2 text-[#6E6E73] hover:bg-[#F5F5F7] text-sm
  数值：w-9 text-center text-sm font-medium text-[#1D1D1F]
  ＋ 按钮：同 − 按钮
```

**ToggleSwitch（macOS 风格开关）**
```
h-6 w-11 rounded-full
开：bg-[#C25338]
关：bg-[#D2D2D7]
禁用：opacity-40 cursor-not-allowed
```

### 5.8 空状态（Empty State）

```
任务页：h-[300px] bg-white border border-[#E5E5EA] rounded-xl
       flex flex-col items-center justify-center text-center

图标容器：w-14 h-14 rounded-full
进行中为空：bg-[#FBEFED]，图标 text-[#C25338]
其他状态为空：bg-[#F5F5F7]，图标 text-[#C7C7CC]

标题：text-[15px] font-medium text-[#1D1D1F]
说明：mt-1.5 text-[12px] text-[#9E9EA8]

主操作（仅进行中为空）：mt-4，使用紧凑主要按钮
```

- 空状态卡片高度固定，不随窗口高度无限拉伸；卡片下方允许保留呼吸空间。
- 已完成与已放弃为空时不重复提供创建入口，避免操作语义错位。

### 5.9 徽标/状态标签

```
text-[10px] font-medium px-1.5 py-0.5 rounded

今日已达标：bg-[#EDF3F0] text-[#547A66] border border-[#C6D8CF]
已放弃：    text-[#C7C7CC] border border-[#E5E5EA]
警告类：    bg-amber-50 text-[#B7791F]
```

## 六、图标规范

- 全部使用内联 SVG，不引入图标库
- `viewBox="0 0 14 14"` 或 `0 0 16 16` 或 `0 0 24 24`（统一即可）
- `fill="none" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" strokeLinejoin="round"`
- 尺寸：列表行内 `w-3.5 h-3.5`，导航 `w-4 h-4`，页面级 `w-5 h-5`
- **不得使用 emoji 作为图标**

## 七、交互规范

### Hover 显示操作区
任务行的操作按钮（开始专注、完成、编辑、删除）默认隐藏，鼠标 hover 时显示：
```tsx
const [hovered, setHovered] = useState(false)
onMouseEnter={() => setHovered(true)}
onMouseLeave={() => setHovered(false)}
{hovered && <div className="flex items-center gap-1">...</div>}
```

### 二次确认
危险操作（完成任务、删除、放弃）必须展示行内确认区：
```
[说明文字]  [取消]  [确认按钮]

说明：text-[12px] text-[#6E6E73]
取消：text-[12px] text-[#9E9EA8] hover:text-[#6E6E73]
确认：text-[12px] font-medium text-white bg-[#547A66] px-3 py-1 rounded-lg
```
鼠标移出后自动取消确认状态（`onMouseLeave` 重置）。

### 过渡动画
- 状态切换：`transition-colors`（颜色类）、`transition-all`（多属性）
- 持续时间不写则用默认 `duration-150`
- 进度条宽度：`transition-all`（style width 变化）
- 计时器环：`style={{ transition: 'stroke-dashoffset 0.8s linear' }}`

## 八、布局禁忌

❌ 不要用 `text-sm`、`text-xs`、`text-base`——用精确 `text-[Npx]`  
❌ 不要用 `p-4`、`py-4` 在卡片内——用 `px-4 py-3`  
❌ 不要引入新颜色——只用色板内的值  
❌ 不要用 `font-bold`——最高用 `font-semibold`（仅标题）  
❌ 不要给每个元素加 margin——优先用父级 `gap` 或 `space-y`  
❌ 不要用全局 `* { margin: 0 }` 重置——项目已有 `box-sizing` 重置  
❌ 不要用 `flex-col` 配 `items-start` 做表单——用 `space-y-4` + `block label`  
❌ 不要自己画边框分隔线——用 `border-t border-[#E5E5EA]`（颜色固定）

## 九、页面结构模板

### 列表类页面（如任务页）


```tsx
<div className="flex flex-col items-center min-h-full bg-[#F5F5F7]">
```


## 十、文案规范

- 操作按钮：动词开头，2–4 字，简洁（开始专注、完成任务、保存、取消）
- 说明文字：陈述句，不超过 20 字，结尾不加句号（`每日达标后可追加，不结转未完成数量`）
- 错误提示：以"请"或直接说问题（`名称不能为空`、`截止日期须晚于开始日期`）
- 状态标签：2–5 字名词（`今日已达标`、`已放弃`、`运行中`）
- 空状态：友好简短（`还没有进行中的任务`），可配操作链接
- **不使用感叹号**，不写"请注意"、"提示"等前缀
