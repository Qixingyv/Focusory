# Focusory 产品文档索引

本目录按「产品范围 → 用例与规则 → 领域逻辑 → 原型交互 → 视觉规范 → 交付路线」组织。功能级流程和测试追踪位于 [`功能/`](./功能/README.md)。

## 阅读顺序

1. [`01-产品需求.md`](./01-产品需求.md)：产品目标、MVP 范围、信息架构和整体验收标准。
2. [`02-用户故事.md`](./02-用户故事.md)：角色、用例、失败流程及编号化业务规则，是产品行为的唯一真值源。
3. [`03-逻辑视图.md`](./03-逻辑视图.md)：核心业务对象、关系、交互和状态流转。
4. [`04-原型交互说明.md`](./04-原型交互说明.md)：页面、状态、操作和核心原型路径。
5. [`05-原型UI规范.md`](./05-原型UI规范.md)：原型视觉 Token、组件和交互表现；生产实现需映射为 SwiftUI 与 Asset Catalog。
6. [`06-路线图.md`](./06-路线图.md)：在不改变产品基线的前提下安排实现阶段。

## 真值边界

- 产品范围以 `01-产品需求.md` 为准。
- 用例规格和编号化业务规则以 `02-用户故事.md` 为准；其他文档只引用，不重复定义规则。
- 领域对象和状态机以 `03-逻辑视图.md` 为准。
- 页面行为以 `04-原型交互说明.md` 为准，颜色、尺寸和组件表现以 `05-原型UI规范.md` 为准。
- 单项功能的端到端流程、实现位置、验收标准和测试覆盖以 `功能/` 下对应文档为准。

若文档发生冲突，先按上述边界确定真值来源，再同步修正其他文档，不在下游文档中创建第二套规则。
