# Focusory

个人番茄钟项目：macOS 客户端前端 + Python 后端，同时作为 AI 辅助全流程开发的练习项目。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `Focusory/Focusory/` | macOS SwiftUI 前端源码 |
| `Focusory/Focusory.xcodeproj` | Xcode 工程 |
| `Focusory/FocusoryTests/`、`Focusory/FocusoryUITests/` | 前端测试 |
| `backend/` | Python 后端（`src/` 源码、`tests/` 测试、`alembic/` 迁移） |
| `文档/` | 产品、架构与 AI 开发文档，见下方索引 |
| `AGENTS.md` | AI 协作规则与职责边界 |

## 文档索引

本文档按读者和用途组织。产品文档说明要做什么，架构文档说明系统如何承载产品行为，AI 开发文档约束 Codex 协作方式，个人学习资料不纳入 Git。

## 验证

- 后端修改后运行后端测试或检查命令；前端修改后运行构建、测试或静态检查，具体命令见 [文档/架构/02-开发视图.md](文档/架构/02-开发视图.md) 与 `AGENTS.md` 的「验证约定」。
- 如果当前无法运行验证命令，说明原因和已完成的人工检查。

## 当前职责分支

技术分支维护客户端、测试、资源、工程、根目录 backend/ 与可执行 SQL；业务设计分支维护产品、架构、开发规则和项目级 AI 配置。两个分支都保留完整项目，公共治理文件同步；具体任务与当前分支见[任务台账](文档/AI开发/任务卡/README.md)。
