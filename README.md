# Focusory

个人番茄钟项目：macOS 客户端前端 + Python 后端，同时作为 AI 辅助全流程开发的练习项目。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `Focusory/Focusory/` | macOS SwiftUI 前端源码 |
| `Focusory/Focusory.xcodeproj` | Xcode 工程 |
| `Focusory/FocusoryTests/`、`Focusory/FocusoryUITests/` | 前端测试 |
| `Focusory/backend/` | Python 后端（`src/` 源码、`tests/` 测试、`alembic/` 迁移） |
| `文档/` | 产品、架构、AI 开发、学习文档，见下方索引 |
| `AGENTS.md` | AI 协作规则（Codex/OpenCode 分工与约束） |
| `opencode.json` | OpenCode 配置 |

## 文档索引

本文档按读者和用途组织。产品文档说明要做什么，架构文档说明系统如何承载产品行为，AI 开发文档约束 Codex 协作方式，学习资料记录个人学习过程。

| 视图 | 一句话定义 | 文档 | 什么时候改 |

**速查主线**：用例视图驱动其他四个视图。开工前只问一句——这次改动是否影响用户流程或核心领域模型？影响就先更新用例视图，再检查逻辑、开发、过程和物理视图；不影响则只改代码、不动视图。这条主线之外的细节都按上表按需查。

### 文档分区

- [产品](文档/产品/README.md)：按阅读顺序编号的需求、用例、逻辑视图、原型、UI 规范、路线图和功能级文档。
- [架构](文档/架构/01-架构总览.md)：按阅读顺序编号的架构总览、开发/过程/物理视图、API、数据模型、参考 DDL、代码注释原则和 SwiftUI 样式规则。
- [AI 开发](文档/AI开发/README.md)：按阅读顺序编号的 Codex 协作流程、项目配置、辅助工具和决策记录。
- [学习](文档/学习)：Swift、Python 后端、操作系统等个人学习资料，不作为产品或架构基线。

### 学习路线

- [苹果开发学习路线](文档/学习/Swift/苹果开发学习路线.md)：按 Swift、SwiftUI、状态、网络、存储、测试和发布组织的独立学习顺序。
- [Swift 与 SwiftUI 语法手册](文档/学习/Swift/swift语法笔记/)：结合 Focusory 当前代码解释 Swift 和 SwiftUI 语法。
- [Python 后端学习路线](文档/学习/Python/Python后端学习路线.md)：按 Focusory 的 Python 3.12.10、FastAPI、SQLAlchemy、MySQL 和 Alembic 技术基线组织的学习与项目实践顺序。
- [Python 语法手册](文档/学习/Python/Python语法手册.md)：覆盖后端主线需要的现代 Python 语法、类型、异常、测试和同步/异步边界。
