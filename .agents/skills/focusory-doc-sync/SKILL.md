# Focusory 文档同步

处理功能变更时：

1. 从 `文档/产品/功能/README.md` 确认功能编号和对应 UC；没有匹配项时，先判断是扩展现有功能还是新增用户能力。
2. 以 `文档/产品/02-用户故事.md` 中的用例和业务规则为需求基线，不在功能文档中复制规则定义。
3. 更新对应功能文档的主流程、异常分支和 Mermaid 主流程图。
4. 检查逻辑、开发、过程和物理视图是否受到影响，只修改确实发生变化的视图。
5. 补充实现位置、验收标准与测试覆盖，并更新功能索引中的文档和流程图状态。
6. 总结已同步的文档和仍待确认的偏移，不用猜测填补缺失的产品决策。
