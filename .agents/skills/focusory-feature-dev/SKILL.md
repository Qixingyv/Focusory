# Focusory 功能开发

实现 Focusory 功能时，按以下流程执行：

1. 阅读 `文档/产品/功能` 中的对应功能文档，以及 `文档/产品`、`文档/架构` 和 `文档/AI开发` 下的相关文件。
2. 编辑前先检查已有前端和后端代码。
3. 复述目标行为，并识别最小可实现范围。
4. 当功能流程、接口或数据模型契约变化时，同步更新功能流程图和相关 IBM 4+1 文档。
5. 小步实现后端和前端改动。
6. 运行可用测试或检查命令。
7. 总结改动文件、验证结果和后续需要记录的决策。
